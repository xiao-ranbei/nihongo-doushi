# 言の葉 · 日语学习工具（网页端）

一个离线可用的日语学习网页，当前包含动词、形容词、助词学习与文章阅读（AI 解析，需用户自备模型服务）模块；除 AI 解析外不依赖外部服务或第三方题库。产品方向与目标设计见[项目文档索引](../docs/README.md)。

## 使用

用浏览器打开本目录的 `index.html` 即可进入学习主页。选择动词、形容词或助词模块后开始学习；动词与形容词练习支持汉字、假名或常见罗马字输入。答题统计和错题保存在当前浏览器中，练习区可单独清零统计，不会删除错题。

## 练习内容

- 五段、一段和不规则动词，共 173 词（五段 98／一段 51／不规则 24）；练习目标为 7 种语态 × 18 种活用形式
- 敬语子页：三层（尊敬語／謙譲語／丁寧語）对照与填空练习、15 条特殊敬语动词、敬语诊断、二重敬语检查、6 个场景各 4 句手写例句；侧栏有独立入口
- 学习主页汇总今日答题量、连续学习天数和各模块今日状态
- 动词、形容词和助词作为独立模块，通过侧栏导航切换；窄屏使用左侧抽屉
- 助词模块默认进入练习：综合模式交替出“选择合适助词”和“判断目标助词在句中作用”两类题；层级与题型可用下拉框切换，学习地图与错题复习作为辅助入口
- 助词句义题在完整句子中高亮目标助词，使用四个同类选项判断其当前作用，作答后再显示译文与解析，避免把上下文关系和助词本身混为一谈
- 助词学习地图每条例句给出「换个助词会怎样」，即同一语境换掉助词后意思怎么变；选助词题答错时，反馈会针对**你选的那一项**说明为什么不成立，而不只是给整句解析
- 三个模块共用页签、说明卡、练习控制面板和答题统计条；助词统计可独立清零，不影响错题或每日练习记录
- 形容词练习与速查：覆盖い／な形容词的常见接续、时态、否定和特殊变化
- 动词与形容词速查页解释未然形、連用形、終止形、連体形、仮定形、命令形；动词例子随所选词更新，形容词对照「高い／静か」并提供条件形练习
- 动词和形容词的活用形式筛选包含六形语境题；题目按具体接续出题，沿用现有答题统计与错题复习，形容词命令形使用礼貌替代表达
- 题干关键词、规则提示和形容词词尾变化统一使用同一套高亮样式
- 动词卡片初始隐藏读音和动词类别，点击卡片可切换显示；检查答案后自动显示
- ます词干、ます形、否定、过去、て形、条件形、意向形、命令形等活用
- 可能、受身、使役、短使役、使役受身等派生形
- 答对／答错次数统计融入练习卡；作答后整张练习卡以绿色或红色扫光反馈，并显示变化提示、活用大意和规则说明
- 随机题每轮不重复相同的动词与变形组合；尽量避免最近 3 题内重复同一动词，题池用完后重新洗牌
- 练习范围可按动词类别、变形类型、活用形式、难度（基础／进阶）四个维度筛选；指定具体活用形式时难度筛选自动停用
- 错题采用简化间隔复习：答错后隔 4 道已作答题重现；答对后按 1、3、7、14、30 天拉长间隔，连续答对 6 次后移出
- 活用速查表按 基础活用/进阶活用 分组，每行可「练这题」，直接把查到的形式变成一道题；错题重练时有常驻横幅显示本轮待练题数，可随时退出
- 活用速查页可展开查看各变形类型的五列表格，包含当前动词例形、常见表达大意、变化提示与直接练习入口；说明会随五段、一段和不规则动词切换

题目和活用规则由本工具独立实现；不使用目标网站的源代码、素材或动词数据。

## 字体

页面使用霞鹜楷体（`font/LXGWZhenKaiGB-Regular.ttf`，约 16.7MB）。运行时实际加载的是按当前词库与界面文本生成的子集 `LXGWZhenKaiGB-Regular.subset.woff2`（约 466KB，字符表 1542 项 / cmap 1540 字形，字形轮廓与步进宽度与原字体一致）。同一脚本还会产出 Android 端 TTF `android/app/src/main/res/font/lxgw_zhenkai_subset.ttf`（约 843KB，与 woff2 同一字符表，D-029），两端必须一起重建。新增词库或界面文本后，重新生成子集：

```text
pip install fonttools brotli
python font/subset.py
```

脚本会收集字符、生成 woff2、校验字形覆盖与轮廓一致性，并把 `font/fonts.js` 指向新文件。全量字体只在该脚本运行时需要。

漏字不只是"字形不好看"：回退字体的行高与楷体不同，实测新增「难度」二字而忘记重跑子集时，筛选栏行高由 12.5px 变成 16.67px、整页下移 5px。`tests/font.test.js` 会拦截这种情况。

# 日语学习工具 · 网页端

一个离线可用的日语学习网页，当前包含动词和形容词两个独立模块，不依赖外部服务或第三方题库。产品方向与目标设计见[项目文档索引](../docs/README.md)。

## 使用

用浏览器打开本目录的 `index.html` 即可进入学习主页。选择动词或形容词模块后开始练习；输入答案时可以使用汉字、假名或常见罗马字。答题统计和错题保存在当前浏览器中，练习区可单独清零统计，不会删除错题。

## 练习内容

- 五段、一段和不规则动词
- 学习主页汇总今日答题量、连续学习天数和各模块今日状态
- 动词与形容词作为独立模块，通过侧栏导航切换；窄屏使用左侧抽屉
- 形容词练习与速查：覆盖い／な形容词的常见接续、时态、否定和特殊变化
- 动词卡片初始隐藏读音和动词类别，点击卡片可切换显示；检查答案后自动显示
- ます词干、ます形、否定、过去、て形、条件形、意向形、命令形等活用
- 可能、受身、使役、短使役、使役受身等派生形
- 答对／答错次数统计融入练习卡；作答后整张练习卡以绿色或红色扫光反馈，并显示变化提示、活用大意和规则说明
- 随机题每轮不重复相同的动词与变形组合；尽量避免最近 3 题内重复同一动词，题池用完后重新洗牌
- 练习范围可按动词类别、变形类型、活用形式、难度（基础／进阶）四个维度筛选；指定具体活用形式时难度筛选自动停用
- 错题采用简化间隔复习：答错后隔 4 道已作答题重现；答对后按 1、3、7、14、30 天拉长间隔，连续答对 6 次后移出
- 活用速查表按 基础活用/进阶活用 分组，每行可「练这题」，直接把查到的形式变成一道题；错题重练时有常驻横幅显示本轮待练题数，可随时退出
- 活用速查页可展开对照各变形类型的变化规则与当前动词例子，规则会随五段、一段和不规则动词切换

题目和活用规则由本工具独立实现；不使用目标网站的源代码、素材或动词数据。

## 测试

安装 Node.js 后，在 `web/` 目录运行：

```text
node --test tests/verb-engine.test.js tests/adjective-engine.test.js tests/styles.test.js tests/font.test.js tests/ui.test.js
```

Windows 下 `node --test` 需要显式列出文件，不能只传 `tests/` 目录。

| 测试文件 | 覆盖内容 |
| --- | --- |
| `verb-engine.test.js` | 变形规则、答案归一化、罗马字转换 |
| `adjective-engine.test.js` | 形容词变形、特殊形式、答案变体与规则说明 |
| `styles.test.js` | 样式契约守卫（令牌必须已定义、组件内禁止硬编码色值） |
| `font.test.js` | 字体契约守卫（子集字符表与源码一致、清单指向的文件存在且未误提交全量字体） |
| `ui.test.js` | UI 冒烟：用零依赖 DOM 桩加载 `app.js`，覆盖出题、判定、筛选、速查练习闭环、间隔复习与存档容错 |

## 字体

页面使用霞鹜楷体（`font/LXGWZhenKaiGB-Regular.ttf`，约 16.7MB）。运行时实际加载的是按当前词库与界面文本生成的子集 `LXGWZhenKaiGB-Regular.subset.woff2`（约 240KB，837 个字符，字形轮廓与步进宽度与原字体一致）。新增动词或界面文本后，重新生成子集：

```text
pip install fonttools brotli
python font/subset.py
```

脚本会收集字符、生成 woff2、校验字形覆盖与轮廓一致性，并把 `font/fonts.js` 指向新文件。全量字体只在该脚本运行时需要。

漏字不只是"字形不好看"：回退字体的行高与楷体不同，实测新增「难度」二字而忘记重跑子集时，筛选栏行高由 12.5px 变成 16.67px、整页下移 5px。`tests/font.test.js` 会拦截这种情况。

## 开发工具（可选，运行时不依赖）

| 工具 | 用途 |
| --- | --- |
| `font/subset.py` | 字体子集化与校验 |
| `tools/color-audit.py` | 统计并聚类 `styles.css` 中的硬编码色值 |
| `tools/tokenize-colors.py` | 把硬编码色值替换为语义令牌并校验变量定义 |
| `tools/visual-check.js` | 用 Playwright 截取 12 个主页、模块和练习状态 |
| `tools/visual-diff.py` | 逐像素对比两组截图，输出差异热图 |

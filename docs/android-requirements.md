# Android 原生客户端需求

> 状态：MVP 已实现（2026-10-14，见 D-015 与 `android/`）；导航原型及未来工具选项待后续阶段决定。

## 1. 定位

Android 应用是日语学习工具集的原生客户端，与现有网页共同属于本仓库。它不是把网页简单装进 WebView；界面和规则引擎使用 Kotlin 原生实现。未来可以承载不同形态的日语工具，不限于练习题。

## 2. MVP 已确认需求

| 领域 | 确认内容 |
| --- | --- |
| 首版功能 | 学习主页、动词练习、形容词练习、按模块分组的全局错题复习 |
| 暂缓功能 | 完整活用速查、错题导入／导出、其他新工具 |
| 技术方向 | Kotlin 原生 UI 和引擎；网页保留 JavaScript 引擎 |
| 一致性 | 当前共同支持的动词、形容词在两端给出相同结果；使用共用样例验证 |
| 网络 | 首版完全离线；题库、规则和学习记录可本机使用 |
| 账号与同步 | 首版不提供账号、云同步、Web 数据自动迁移 |
| 本地数据 | Android 数据单独保存在本机；暂不做 Android 备份／恢复 |
| 发布 | 先生成供本人或小范围测试的签名 APK，不以 Google Play 上架为首发要求 |
| 系统功能 | 首版不需要额外通知、语音、桌面组件或后台任务 |
| 设备范围 | 手机竖屏优先，适配不同手机尺寸；平板和横屏后续评估 |
| 视觉 | 保留网页纸感配色与品牌氛围；返回、键盘、导航等遵循 Android 习惯 |

卸载或设备损坏可能丢失本地学习记录；首版接受此限制。

## 3. 现有网页与 Android 的关系

- 当前动词和形容词模块首版保持能力对齐。
- Web 使用 JavaScript 引擎，Android 使用 Kotlin 引擎；不通过 WebView 桥接来共享 UI 或规则执行。
- 新增或修正规则时维护一组跨端共用的输入／期望输出样例，分别运行于 JavaScript 和 Kotlin 测试。
- 后续语音对话、日语文章解析等工具是否同时进入 Web，按当时的产品需求决定，不预先承诺全平台对齐。
- 未来联网工具可以加入 Android 工具集，但须按模块另行确认网络数据、权限、隐私提示和离线行为。

## 4. 同仓库组织

当前网页客户端已位于 `web/`。Android 工程开始时，在仓库根目录新建 `android/`，与 `web/` 并列维护。

## 5. 工程选项（2026-10-14 确定，见 decisions.md D-015）

- 最低支持版本：minSdk 26（Android 8.0+）；compileSdk / targetSdk 35。
- UI 工具包：Jetpack Compose（Material 3），配色 Token 从 `web/styles.css` 的 `:root` 语义令牌移植；图标统一使用 Material Icons，不用 emoji。首版页面切换用状态管理实现，不引入 Navigation 库。
- 应用包名：`com.nihongodoushi.app`；应用图标与签名分发细节在出签名 APK 前确定。
- 本地存储：kotlinx-serialization 版本化 JSON 文件（对应 Web 端 localStorage 各键的结构），错题、统计、每日练习各一个文件；今日活动计数直接复用该结构。
- 平板、横屏、折叠屏和辅助功能的支持范围仍延后。

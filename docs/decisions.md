## 明确延后的决定

- Android 最低支持版本、Kotlin UI 框架、本地存储技术和包名。
- Android 原生主页／侧栏／抽屉／底部导航的最终组合。
- 平板、横屏和折叠屏支持。
- 未来联网工具的服务提供方、发送数据、权限和本地／远程处理方式。
- 学习主页对非答题型工具的“今日活动量”计算规则。

# 产品方向与范围

> 状态：目标方向已确认。主页、侧栏和 Android 客户端仍属于待实现目标。

## 产品定位

面向日语学习者的本地学习工具集。用户从统一的学习主页进入按知识领域划分的模块；模块可以是规则练习、速查，也可以是后续的语音对话或文章解析工具。

## 产品目标

1. 提供清楚的学习入口，让用户能从学习主页找到合适的日语工具。
2. 让动词、形容词等模块拥有自己的内容、规则、筛选和详细统计。
3. 统一整体品牌和基础交互；共享适合跨模块使用的学习服务，如全局连续学习记录和分组错题本。
4. 保持核心练习离线可用；将来确需联网的工具按模块明确说明网络、权限和隐私边界。
5. 让新模块可以按统一约定接入，但当前不建设插件注册框架。

## 用户与核心体验

目标用户是希望按日语知识领域自主学习和练习的人。主要体验路径是：

```text
打开应用
  → 学习主页查看今日练习量、连续学习和模块状态
  → 进入动词、形容词或其他日语工具
  → 在模块内练习、查阅或使用工具
  → 在模块内查看细节，必要时从全局错题本继续复习
```

## 产品范围

### 当前网页能力

网页端目前提供动词和形容词练习、速查、统计、共享错题复习和本地连续打卡。当前实现情况见 [current-state.md](current-state.md)。

### 已确认的目标能力

- **学习主页：** 每次启动时默认显示；提供整体与分模块的今日练习量、连续学习天数和模块状态。详细正确率等统计仍留在模块内；首版不要求每日目标或知识点掌握度模型。
- **独立模块：** 模块共享品牌、外壳和通用服务，但内容、规则、筛选和详细统计由模块负责。
- **共享复习：** 提供按模块分组的全局错题本；模块可以提供进入本模块错题的快捷入口。
- **Android 首版：** 原生 Kotlin 工具集，包含学习主页、动词和形容词练习、共享错题复习；速查和导入／导出后续再评估。
- **平台范围：** 当前动词、形容词能力在 Web 与 Android 之间保持对齐。未来模块是否跨平台按阶段需求决定。

### 未来方向而非首版承诺

可考虑加入助词、句型、汉字、语音对话、日语文章解析等日语学习工具。未来工具不一定都是题目练习，也不要求首版全部支持 Web 与 Android。

## 产品原则

- **日语学习范围：** 当前产品不定位为跨学科通用学习平台。
- **模块自主：** 不强迫所有模块使用同一种交互；练习、速查、对话和文章分析可选择合适的页面能力。
- **风格一致、交互合适：** 共享纸感配色和品牌氛围；Android 使用符合平台习惯的返回、键盘和导航交互。
- **离线优先、联网显式：** 首版核心功能无需网络；未来联网模块需说明发送的数据、所需权限、失败状态及离线边界。
- **本地优先：** Web 与 Android 记录首版分别保存在本机，不做账号、云同步或自动迁移。
- **渐进扩展：** 先按明确约定手工接入模块；确认多个模块出现稳定共性后，再考虑抽象注册机制。

# 底部栏两标签重设计 · 主页 / 我的

> 日期：2026-10-15  
> 状态：**已确认并实现**（2026-10-15，见 §8 选定清单与 §9 实现记录）  
> 原型：`docs/design/home-mine-prototypes.html`（三版，框内底栏可点击切换两页）  
> 关联：`docs/android-answer-screen-spec.md`（答题界面规格）

## 1. 这次改动的性质

底栏从**四个平级标签**（主页 / 动词 / 形容词 / 错题本）收敛为**两个标签**（主页 / 我的）——这是信息架构（IA）调整，不只是换皮：

| 维度   | 改前              | 改后                                             |
| ---- | --------------- | ---------------------------------------------- |
| 一级页面 | 4 个（答题界面直接挂在底栏） | 2 个（主页、我的）                                     |
| 二级页面 | 无               | 动词练习、形容词练习、错题本（从主页入口进入）                        |
| 返回方式 | 无需返回            | 二级页顶部返回箭头 + 系统返回键；**练习中返回不丢当前题**（状态已提升在根级，无需改） |
| 扩展性  | 加模块要动底栏         | 加模块只加主页入口行                                     |
| 代价   | —               | 进模块多一次点击 → 用大热区入口卡补偿                           |

## 2. 底部栏规格（两页共用）

| 项    | 规格                                                                                 |
| ---- | ---------------------------------------------------------------------------------- |
| 高度   | 68dp + 底部安全区内边距（模拟手势条 14dp）                                                        |
| 背景   | `--surface` + 上边框 1dp `--line`                                                     |
| 标签数  | **固定 2 个**，等宽居中（左右各留 46dp 视觉边距）                                                    |
| 选中态  | **绿色 pill 底**（`--green-pale`，圆角 999，内距 5×22）+ 图标主色 `--green` + 文字加粗 `--green-dark` |
| 未选中态 | 图标与文字 `--muted`，无底色                                                                |
| 切换逻辑 | 点标签即切换页面，页面内容用 200ms 上移淡入；两页各自保留自己的滚动位置与状态                                         |
| 图标   | 主页 = 房子；我的 = 人像。Material Icons 填充风格，21dp                                           |

选中态用「底色 + 颜色 + 字重」三重表达，比只换颜色更醒目。

## 3. 主页：功能模块统一入口

### 3.1 结构（自上而下四段）

| 段 | 区域           | 内容与作用                            | 层级 / 视觉权重                                   |
| - | ------------ | -------------------------------- | ------------------------------------------- |
| ① | 页头           | 日期 + 一句主标题（如「今天继续」）              | 第三权重：11.5sp 灰日期 + 23sp 主标题                  |
| ② | 今日概览 / 进度主视觉 | 今日答题量、连续天数、正确率；或今日目标完成度          | **第一权重**：纸白卡，最大数字 21–30sp，主色 `--green-dark` |
| ③ | 模块入口区        | 动词练习 / 形容词练习 / 错题本（+ 未来「活用速查」占位） | **第二权重**：可点卡片，热区 ≥ 56dp，右箭头提示可进入二级页         |
| ④ | 待办提示（条件出现）   | 「2 道错题今天到期」这类需要行动的信息             | 第四权重但高对比（淡橙底 `--orange-pale`），**无事项时不占位**   |

每个入口卡的副信息回答「进去之后面对什么」：词条数、上次练到哪个形式、有多少错题到期。

### 3.2 三版差异（原型可点）

| 版本          | ② 主视觉                      | ③ 入口形态                       | 适合                     |
| ----------- | -------------------------- | ---------------------------- | ---------------------- |
| **v1 卡片优先** | 横向概览条（三格数字）                | 三张**大卡**（图标 + 标题 + 副信息 + 箭头） | **推荐**：热区最大，单手一屏可进任何模块 |
| v2 数据优先     | **大进度环**（今日目标完成度，环内 12/20） | 三个**紧凑卡**横排                  | 进度感最强，但入口热区变小          |
| v3 清单优先     | **一周打卡条**（7 天，今天高亮）        | **列表行**（可容纳更多模块）             | 信息密度最高，模块继续增加时最稳       |

## 4. 我的：今日学习统计

### 4.1 结构（自上而下三段）

| 段 | 区域    | 内容与作用                               | 层级 / 视觉权重                    |
| - | ----- | ----------------------------------- | ---------------------------- |
| ① | 时长主卡  | 今日学习时长（46sp 大数字）+ 完成任务数 / 答题数 / 正确率 | **第一权重**：整页视觉锚点              |
| ② | 学习进度区 | 词库覆盖（已练/总数）、错题掌握（毕业/总数）、连续天数、本周累计   | **第二权重**：指标格或进度条，条高 5–7dp    |
| ③ | 今日明细  | 分模块明细（动词/形容词各自的题量、时长）、口径说明          | 第三权重：14–15sp 标题 + 11.5sp 副信息 |

### 4.2 三版差异

| 版本                | ① 形态                 | ② 形态                                  | 适合               |
| ----------------- | -------------------- | ------------------------------------- | ---------------- |
| **v1 时长主卡 + 指标格** | 46sp 大数字             | 2×2 指标格（每个带进度条）                       | **推荐**：数字最大、最易扫读 |
| v2 三环 + 明细        | 三个小环并列（时长 / 任务 / 覆盖） | 明细列表（一行一指标，含口径注释）                     | 三个维度一眼看全         |
| v3 模块进度条 + 明细     | 紧凑双数字条               | **模块横向进度条**（动词 12/44、形容词 6/15、错题 2/9） | 最直观回答「学到哪了」      |

## 5. 视觉风格与信息优先级

**沿用现有纸感体系，不新造色**：页面底 `#f6f5f0` → 纸白卡 `#fffefa` + 1dp 描边 + 双层轻阴影 → 语义淡色（淡绿 `#edf3eb` / 淡橙 `#f8efe6`）三级层次。

| 令牌                                   | 用途（两页中）                 |
| ------------------------------------ | ----------------------- |
| `--green-dark #254a3d`               | 关键数字（时长、今日答题、连续天数）      |
| `--green #326151`                    | 进度条、选中态、主按钮             |
| `--orange #b8784f` / `--orange-pale` | 「需要行动」的提示（错题到期）、错题掌握进度条 |
| `--red #a54e45` / `--red-pale`       | 仅错题相关语义                 |
| `--text-strong #657268`              | 副信息（副标题、指标名）            |
| `--muted #7b867e`                    | 三级信息（日期、口径注释）           |

**优先级通则**：一屏内只允许一个「大数字锚点」（主页是今日进度相关，我的页是学习时长）；同一行内文字层级不超过两级；需要用户行动的用暖色，纯展示的用中性色。

**禁项**（沿用项目红线）：emoji 作图标、紫粉渐变、硬编码颜色、弹跳缓动。

## 6. 数据口径：这一页能不能上，取决于这张表

「我的」页要求的三项指标里，**只有一项现成可用**：

| 指标         | 现状    | 口径与采集建议                                            |
| ---------- | ----- | -------------------------------------------------- |
| 今日答题数      | ✅ 已有  | `daily-v1.verbAnswers / adjectiveAnswers`          |
| 连续学习天数     | ✅ 已有  | `daily-v1.streak / best`                           |
| 正确率        | ✅ 已有  | `stats-v1.correct / incorrect`（建议统一「本轮累计」口径）       |
| 错题掌握       | ✅ 已有  | 错题本 `correctStreak`（连续答对 6 次毕业）                    |
| **学习时长**   | ❌ 需新增 | 前台计时：进入练习屏开始，退到后台/离开模块暂停；按模块累加。**仅本地、不上报**         |
| **完成任务数**  | ❌ 需新增 | 沿用现有「一轮 5 题」（`ROUND_SIZE`）：完成一轮 +1，完成一次错题重练 +1     |
| **词库覆盖进度** | ❌ 需新增 | 记录「已练过的词条 id 集合」，进度 = 已练 ÷ 总数（动词 44 + 形容词 15 = 59） |

**存储扩展建议**（遵守项目红线：新键带版本号 + 防御性校验）：

| 新键            | 内容                                                 | 说明                            |
| ------------- | -------------------------------------------------- | ----------------------------- |
| `activity-v1` | `{ lastDate, verbSeconds, adjSeconds, tasksDone }` | 今日学习行为；跨日重置逻辑与 `daily-v1` 一致  |
| `practice-v1` | `{ verbIds: [...], adjIds: [...] }`                | 已练词条集合；用 id 数组，量级 < 100，无性能问题 |

两者都属**可选增强**：不做，则「我的」页只能显示已有四项（答题数、正确率、连续天数、错题掌握）。

## 9. 实现记录（2026-10-15 落地）

### 9.1 新增采集与存储

| 键                                    | 结构                                                                                  | 写入时机                                   |
| ------------------------------------ | ----------------------------------------------------------------------------------- | -------------------------------------- |
| `japanese-verb-practice-history-v1`  | `{ days: [{ date, verbAnswers, adjectiveAnswers, seconds, tasks }] }`，保留最近 **14 天** | 答题（计数）、前台计时落盘（秒）、完成一轮（任务）              |
| `japanese-verb-practice-progress-v1` | `{ verbIds: [], adjectiveIds: [], masteredMistakes }`                               | 每题出题时记录词条 id；错题毕业时 masteredMistakes +1 |

- **学习时长**：`StudyTimeTracker` 在练习屏可见期间计时，`ON_PAUSE` 暂停、`ON_RESUME` 续计，离屏时把累计秒数写入 history。**只统计前台时间**，挂机不算。
- **完成任务数**：完成一轮 5 题 +1；完成一轮错题重练 +1。
- **词库覆盖**：出过题即计入已练词条（动词 44 / 形容词 15，共 59）。
- **启动回填**：history 中今日答题数少于 `daily-v1` 时取较大值补齐（幂等、只升不降），保证周历条 / 我的页 / 打卡三处口径一致。
- 时长展示：不足 1 分钟显示秒（避免刚练完显示「0 分钟」）。

### 9.2 导航结构

- 底栏 2 标签：主页、我的（`AppTab`）。
- 二级页：动词练习、形容词练习、错题本 —— 从主页入口进入，**进入后隐藏底栏**，顶部返回箭头 + 系统返回键均可回到主页（`BackHandler`）。
- 练习状态仍在根级提升，进出二级页不丢当前题。

### 9.3 验证结果（模拟器 android-36 实测）

| 项    | 结果                                                                                                           |
| ---- | ------------------------------------------------------------------------------------------------------------ |
| 单元测试 | **36/36**（新增 `ActivityAggregationTest` 5 条：周历七格与今天标记、同日去重与排序、14 天裁剪、覆盖率边界、时长文案）                              |
| 主页   | 周历条今天格显示当日答题数、未来格显示「–」；三张大卡入口文案含词条数与已练数；底栏仅两标签、选中态为绿 pill                                                    |
| 我的页  | 时长「30 秒」（不足 1 分钟显示秒）、完成任务、三条模块进度条（动词 1/44）、今日明细、统计清零入口                                                       |
| 二级页  | 动词练习可进入（顶部返回箭头 + 底栏隐藏），返回键回到主页                                                                               |
| 采集落盘 | `history-v1` 记录 `seconds:30`；`progress-v1` 记录 `verbIds:["kuru"]`；回填后 history 的 `verbAnswers` 与 `daily-v1` 一致 |

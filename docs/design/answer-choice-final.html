区块层级（自上而下，共 6 层）

层级由「底色 → 纸白卡 + 细边 + 双层轻阴影 → 语义淡色」三级构成；同一屏内不再出现第四种表面，保证视觉统一。

区块层级 / 表面内容与职责
状态栏系统层系统状态，不干预；背景与页面纸底同色，避免出现“双色条”。
统计卡纸白卡 + 顶部 3px 进度条 本轮进度（第 n / N 题）· 答对 · 答错 · 剩余 · 正确率大数 · 正确率比例条（绿=答对占比，红=答错占比）。每次判定后数字与条宽同步过渡 300ms。
题面卡纸白卡 模式/类别/目标三个 chip + 楷体大字词条 + 作答指令；判题后原位展开读音与大意（虚线分隔，不跳页）。
选项区纸白卡 × 4（竖排全宽） 方案 A 的核心：整宽热区，序号 1–4 圆角方块；判定后整体转为紧凑态（内边距收紧），为抽屉腾出空间。
判定抽屉浮起卡 + 左侧 3px 语义色条 判题后以 flex item 插入内容区底部（非浮层，不遮挡任何选项），并自动滚入视野；承载判定结果、正确形态、读音、规则说明、错题提示与「下一题」。
底部导航纸白 + 上边框 四目的地固定在底部；抽屉展开时导航位置不变，避免布局跳动。

状态一览（答题闭环 4 态）

原型会真实经历这四种状态；每种状态的视觉差异只允许出现在「选项」「抽屉」「统计卡」三处。

S0 作答中
选项全部可用，悬停淡绿底、按下轻微内缩；抽屉不存在；题面读音/大意折叠。
S1 判对
所选项 绿边绿底 + 勾图标；抽屉为绿左条，标题「答对了」，给出正确形态与规则；答对计数 +1，比例条绿段加宽。
S2 判错
所选项 红边红底 + 叉；正确答案项 绿虚线 + 勾（揭晓）；抽屉为红左条并附「已加入错题本」提示；答错计数 +1，红段加宽。
S3 本轮结束
第 5 题判定后，抽屉切换为本轮小结（对/错/正确率/本轮新增错题），提供「再来一轮」与「去错题本」。

交互逻辑

一次点击完成「选择 + 提交」，没有提交按钮与输入法；判定后立即锁定，杜绝连点错判。

交互行为
点选项 / 1–4立即判定；选项与抽屉同时进入对应状态；抽屉自动滚入视野。
Enter / 「下一题」进入下一题：抽屉收起、选项回到 S0、题面读音与大意复位折叠；统计卡保持累计值。
规律提示题面卡内原位展开（虚线淡绿面板），判题后自动收起——规则改由抽屉承载，不重复占位。
滚动内容区独立滚动；判定后自动滚动到抽屉顶部，回到题目可上滑。导航栏常驻不参与滚动。
错题联动S2 判定即写入错题本（沿用加权出题与间隔复习机制）；抽屉给出反馈提示，不弹额外弹窗。
无障碍选项为原生 button，Tab 可遍历、Enter 激活；判定结果文字进入 liveRegion 播报；色觉障碍下靠「图标 + 边框样式」仍可判读。

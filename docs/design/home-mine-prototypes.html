两页的结构、层级与优先级

三个版本共用同一套结构与视觉规范，差别只在「谁做主视觉」与「信息密度」。下表是确定的骨架，版本差异列在最后一列。

位置区域内容与作用层级与视觉权重版本差异
主页 ① 页头（日期 + 主标题） 今天的日期与一句主标题，给「今天在做什么」定调 第三权重：11.5sp 灰日期 + 23sp 主标题 一致
② 今日概览 / 进度主视觉 今日答题、连续天数、正确率；或今日目标完成度 第一权重：纸白卡 + 最大数字（21–30sp 主色） v1 概览条 / v2 大进度环 / v3 周历条
③ 模块入口区 动词练习 / 形容词练习 / 错题本（+ 未来的速查占位） 第二权重：入口卡可点，热区 ≥ 56dp，右箭头暗示二级页 v1 三张大卡 / v2 三个紧凑卡 / v3 列表行
④ 待办提示（条件出现） 「2 道错题今天到期」等需要行动的信息 第四权重但高对比（淡橙底），仅在有事项时出现 v1 并入错题卡副信息 / v2 独立横幅 / v3 并入列表行
我的 ① 时长主卡 今日学习时长（分钟）+ 完成任务数 + 答题数 + 正确率 第一权重：46sp 时长数字是整页视觉锚点 v1 大数字主卡 / v2 三环并列 / v3 紧凑双数字条
② 学习进度区 词库覆盖（已练/总数）、错题掌握（毕业/总数）、连续天数 第二权重：指标格或进度条，带 5–7dp 进度条 v1 2×2 指标格 / v2 明细列表 / v3 模块横向进度条
③ 明细列表 分模块明细（动词/形容词各自的题量与时长）、口径说明 第三权重：14–15sp 标题 + 11.5sp 副信息 v2/v3 有独立明细；v1 并入指标格
底栏 两个标签 主页 / 我的 选中态 = 绿色 pill 底 + 主色图标 + 加粗文字；未选中 = 灰 一致

导航层级变化（关键）

改前：底栏四个平级标签（主页 / 动词 / 形容词 / 错题本）
改后：底栏两个标签（主页 / 我的），动词、形容词、错题本成为二级页面
返回方式：二级页顶部返回箭头 + 系统返回键；练习中返回不丢当前题（状态提升在根级，已实现）
收益：底栏稳定、模块可扩展（加「听力」「单词」不用动底栏）
代价：进模块多一次点击 → 用大热区入口卡补偿

视觉风格（沿用现有纸感，不新造色）

页面底 #f6f5f0 → 纸白卡 #fffefa + 1dp 描边 + 双层轻阴影 → 语义淡色（淡绿 #edf3eb / 淡橙 #f8efe6）三级层次；
主色 #326151 只用于「数字与激活态」，橙色只用于「需要行动」，红色只用于「错误与错题」；
圆角统一 14–18dp；图标一律 Material Icons（零 emoji）；动效 200ms、统一缓动、禁弹跳。

数据口径：哪些现在就有、哪些要新增采集

「我的」页有三项指标当前存储层拿不到，必须先扩采集才有得显示。这张表是这一页能不能按时上的前提。

指标现状口径与采集建议
今日答题数已有daily-v1.verbAnswers / adjectiveAnswers，主页与我的页共用同一值
连续学习天数已有daily-v1.streak / best，沿用现有「今天或昨天有记录才连续」的判定
正确率已有stats-v1.correct / incorrect；建议统一为「本轮累计」口径（与练习页统计卡一致）
错题掌握已有错题本 correctStreak：连续答对 6 次毕业；「已掌握」= 已毕业数，「总数」= 在册 + 已毕业
学习时长需新增前台计时：进入练习屏开始计时，退到后台 / 离开模块暂停；按模块累加写入 daily-v1 新增字段 verbSeconds / adjSeconds（或新键 activity-v1，带版本号）。不上报、仅本地
完成任务数需新增沿用现有「一轮 5 题」（ROUND_SIZE）：完成一轮 +1；完成一次错题重练也 +1。写入 daily-v1.tasksDone
词库覆盖进度需新增记录「已练过的词条 id 集合」（新键 practice-v1，带版本号 + 防御性校验）；进度 = 已练词条 ÷ 词库总数（动词 44 / 形容词 15，共 59）

请选择

可以整版选，也可以混搭（例如主页用 v1 的大卡、我的页用 v2 的三环）。

Q-A 主页版本：v1 卡片优先（推荐：热区大、一屏进任何模块）／ v2 数据优先（进度感最强，但入口变小）／ v3 清单优先（密度最高，适合模块继续增加）
Q-B 我的版本：v1 时长主卡 + 指标格（推荐：数字最大最好扫）／ v2 三环 + 明细（三个维度一眼看全）／ v3 模块进度条 + 明细（最直观回答"学到哪了"）
Q-C 是否同时扩采集：学习时长 / 完成任务数 / 词库覆盖三项需新增埋点与存储字段；不做则「我的」页只能显示已有四项（答题数、正确率、连续天数、错题掌握）
Q-D 是否保留练习页内的「统计清零」：现挂在筛选抽屉里，若「我的」页承接统计展示，可考虑移到我的页

## 1. 区块层级（自上而下，6 层）

层级规则：底色 → 纸白卡（+ 细边 + 双层轻阴影）→ 语义淡色。同屏不允许出现第四种表面。

| # | 区块 | 表面与层级 | 高度/规格 | 职责 |
|---|------|-----------|-----------|------|
| 1 | 状态栏 | 与页面同色（纸底） | 系统 | 不干预；避免出现双色条 |
| 2 | 统计卡 | 纸白卡 `#FFFEFA` + 1px `--line` + 双层阴影 | 顶部 3px 进度条 + 内容区约 96dp | 本轮进度 · 答对 · 答错 · 剩余 · 正确率 · **比例条** |
| 3 | 题面卡 | 纸白卡 | 约 150dp（展开后约 200dp） | 模式/类别/目标 chips + 楷体大字 + 指令 + 提示；判定后原位展开读音与大意 |
| 4 | 选项区 | 4 × 纸白卡（竖排全宽） | 单条 52dp（判定后紧凑态 44dp） | 单选即判的热区 |
| 5 | 判定抽屉 | 浮起卡 + 左侧 3dp 语义色条 | 自适应内容（约 200–300dp） | 判定结果 · 正确形态 · 读音 · 规则 · 错题提示 · 下一题 / 本轮小结 |
| 6 | 底部导航 | 纸白 + 上边框 | 64dp | 四目的地常驻；抽屉展开时位置不变 |

**抽屉的插入方式（关键）**：抽屉是内容区的 **flex 子项**（判题后插入），不是覆盖式浮层——保证不遮挡任何选项；判题后自动滚动到抽屉顶部。

### 统计卡内部规格

```
┌────────────────────────────────────────────┐
│ 3px 进度条（绿，宽度 = 本轮完成度）              │
│  本轮 第 3 / 5 题              正确率 67%      │
│  答对 2   答错 1   剩余 2                      │
│  ███████████████░░░░░░░░  ← 比例条（绿/红分段）  │
│  正确率比例条              答对 67% · 答错 33%  │
└────────────────────────────────────────────┘
```

| 元素 | 规格 |
|------|------|
| 进度条 | 高 3px，`--green`，宽度 = (已完成题数 / 本轮题数) × 100%，过渡 260ms |
| 轮次文案 | 13.5sp 加粗；「第 n / N 题」中序号用 `--muted` 常规字重 |
| 正确率 | 标签 12sp `--text-strong`，数值 15sp `--green-dark` 加粗 |
| 三格数字 | 答对 `--stat-correct` #54705A / 答错 `--stat-incorrect` #98645B / 剩余 `--text-strong`；数值 17sp 加粗，标签 10.5sp `--muted` |
| **比例条** | 高 8dp，圆角 999；绿段 = 答对占比、红段 = 答错占比（累计口径）；无作答时整条为 `--line-faint`；段宽过渡 300ms |
| 比例条注脚 | 左「正确率比例条」右「答对 x% · 答错 y%」，10.5sp `--muted` |

## 2. 状态机与状态 → 视觉映射

```
S0 作答中 ──点选项/1-4──▶ 判定 ──┬─▶ S1 判对 ──下一题──▶ S0（或 S3）
                                 └─▶ S2 判错 ──下一题──▶ S0（或 S3）
S3 本轮结束（第 N 题判定后取代 S1/S2 的按钮区）
```

| 状态 | 选项区 | 判定抽屉 | 统计卡 | 题面卡 |
|------|--------|----------|--------|--------|
| **S0 作答中** | 4 项全部可用；悬停淡绿底 `--bg-pale-green`，按下轻微内缩 | 不存在（DOM 无节点） | 显示累计值；进度条停止在当前 | 读音/大意折叠；提示可展开 |
| **S1 判对** | 所选项：绿边 `--green` + 绿底 `--green-pale` + 绿勾；其余项保持中性且锁定；全部转紧凑态 | 绿左条；标题「答对了」+ 勾；正确形态大字 + 读音 + 规则 | 答对 +1；比例条绿段加宽 | 原位展开读音与大意；提示面板收起 |
| **S2 判错** | 所选项：红边 `--red` + 红底 `--red-pale` + 红叉；**正确答案项：绿虚线边 + 绿勾（揭晓）** | 红左条；标题「正确答案是「X」」+ 叉；正确形态 + 读音 + 规则 + 「已加入错题本」提示 | 答错 +1；比例条红段加宽 | 同上 |
| **S3 本轮结束** | 保持最后一题判定态 | 抽屉追加「本轮小结」：答对 / 答错 / 正确率 / 本轮新增错题 + 「再来一轮」+「去错题本」 | 保持最终值 | 同上 |

三重冗余：颜色（绿/红）× 图标（勾/叉）× 边框样式（实线=你选的，虚线=正确答案）。色觉障碍下仍可判读。

## 3. 交互细则

| 交互 | 行为 | 备注 |
|------|------|------|
| 点选项 / 数字键 1–4 | 选择 + 提交一步完成，立即判定 | 判定后选项 `locked`，杜绝连点错判 |
| Enter / 「下一题」 | 抽屉收起 → 选项回 S0 → 题面复位 → 内容滚动回顶部 | 统计卡保持累计值不清零 |
| 规律提示 | 题面卡内原位展开／收起（虚线淡绿面板） | 判定后自动收起，规则改由抽屉承载，不重复占位 |
| 滚动 | 内容区独立滚动；判定后自动滚到抽屉顶部 | 导航栏常驻，不参与滚动 |
| 错题联动 | S2 判定即写入错题本，沿用加权出题（封顶 3）与间隔复习（1/3/7/14/30 天，6 次毕业） | 不弹额外弹窗，只用抽屉内提示条 |
| 本轮小结 | 第 N 题判定后出现；「再来一轮」清零本轮计数、「去错题本」切模块 | 累计统计与错题不清零 |
| 无障碍 | 选项为原生可聚焦控件；Tab 遍历、Enter 激活；判定结果进 liveRegion 播报 | contentDescription 例：「第 2 项，正确」 |

动效令牌：卡片入场 `translateY(6px)→0 / 220ms`；选项着色 130ms；抽屉上滑 220ms；数值与条宽过渡 260–300ms。统一缓动 `cubic-bezier(0.22, 0.61, 0.36, 1)`，**禁弹跳曲线**（P0-3）。

## 6. 验收要点（实现后必须实测）

1. 四态截图（S0/S1/S2/S3）与原型逐项对照一致；
2. 选项生成的机械断言：4 项唯一、含正确答案、位置分布近似均匀、误形表每条确实为错误形态；
3. Android 单元测试基线不劣化（当前 22/22）；若新增 quiz 测试则基线上升；
4. 模拟器实测：点选即判、抽屉插入不遮挡选项、自动滚动、小结按钮可用、错题写入正确；
5. 图标接入后实拍三种遮罩下的桌面图标；
6. **跨端一致性**：若同步 Web（待定 Q5），quiz 样例需两端同源比对。

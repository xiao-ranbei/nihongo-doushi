## 1. 区块层级（自上而下，6 层）

层级规则：底色 → 纸白卡（+ 细边 + 双层轻阴影）→ 语义淡色。同屏不允许出现第四种表面。

| # | 区块 | 表面与层级 | 高度/规格 | 职责 |
|---|------|-----------|-----------|------|
| 1 | 状态栏 | 与页面同色（纸底） | 系统 | 不干预；避免出现双色条 |
| 2 | 统计卡 | 纸白卡 `#FFFEFA` + 1px `--line` + 双层阴影 | 内容区约 77dp + 底部 3px 进度条 | 进度环（n/N）· 第 n / N 题 · 答对 x · 答错 y · 正确率 z% |
| 3 | 题面卡 | 纸白卡 | 约 150dp（展开后约 200dp） | 模式/类别/目标 chips + 楷体大字 + 指令 + 提示；判定后原位展开读音与大意 |
| 4 | 选项区 | 4 × 纸白卡（竖排全宽） | 单条 52dp（判定后紧凑态 44dp） | 单选即判的热区 |
| 5 | 判定抽屉 | 浮起卡 + 左侧 3dp 语义色条 | 自适应内容（约 200–300dp） | 判定结果 · 正确形态 · 读音 · 规则 · 错题提示 · 下一题 / 本轮小结 |
| 6 | 底部导航 | 纸白 + 上边框 | 64dp | 四目的地常驻；抽屉展开时位置不变 |

**抽屉的插入方式（关键）**：抽屉是内容区的 **flex 子项**（判题后插入），不是覆盖式浮层——保证不遮挡任何选项；判题后自动滚动到抽屉顶部。

### 统计卡内部规格（按方案 A 统计方式还原）

```
┌───────────────────────────────────────────────┐
│   ╭───╮   第 3 / 5 题                          │
│   │3/5│   答对 2 · 答错 1 · 正确率 67%          │
│   ╰───╯                                        │
│ ████████████░░░░░░░░░░░░  ← 底部 3px 进度条     │
└───────────────────────────────────────────────┘
```

**统计维度（共 4 项，与方案 A 完全一致）**

| # | 维度 | 口径 | 取值来源 |
|---|------|------|----------|
| 1 | 本轮进度（题号） | 当前正在作答的题号 / 本轮题数 | `currentIndex + 1` |
| 2 | 答对累计 | 本轮判定为正确的次数 | 每次判定 +1 |
| 3 | 答错累计 | 本轮判定为错误的次数 | 每次判定 +1 |
| 4 | 正确率 | `round(答对 ÷ (答对 + 答错) × 100)%`；分母为 0 时显示「—」 | 由 2、3 推导 |

**展示形式（4 个元素，与方案 A 一致）**

| 元素 | 规格 |
|------|------|
| 进度环 | 46dp 画布、`r=18`、环宽 4dp、圆头线帽；底环 `#EEF0EB`，进度环 `#326151`；`stroke-dasharray = 2πr × percent ÷ 100`；环内文字 11.5sp 加粗 `--green-dark`，内容为 `n/N` |
| 第一行文案 | 「第 n / N 题」，13.5sp 加粗 `--ink` |
| 第二行文案 | 「答对 x · 答错 y · 正确率 z%」，11.5sp `--muted`；无作答时正确率为「—」 |
| 进度条 | 卡内底部，高 3dp，`--green`，宽度 = 同环的 percent，过渡 260ms |

**计算与更新时机（这是方案 A 的关键语义，别做错）**

- 环 percent = 进度条宽度 = `(当前题号 + 1) ÷ 本轮题数 × 100`——**只反映“当前第几题”，判定后不前进**，进入下一题才推进。
- 第二行文案在**每次判定后立即更新**（答对/答错计数与正确率），此时环与进度条保持不动。
- 正确率是**本轮累计**口径，与统计卡同屏的抽屉内「本轮小结」使用同一公式，两处数字必须一致。
- 进入下一题时：环与进度条前进一格，文字行保持累计值不变。

### 与「三格数字 + 比例条」版本的差异（本轮被替换掉的实现）

| 维度 | 旧实现（本轮替换掉） | 方案 A（现在采用） |
|------|----------------------|--------------------|
| 进度呈现 | 仅卡顶 3px 进度条 | **进度环（含 n/N 文字）+ 底部进度条**，双呈现 |
| 进度语义 | 已完成题数（判定后立即前进） | 当前题号（判定后不前进，下一题才推进） |
| 答对 / 答错 | 三格大数字卡片（17sp） | 一行文字「答对 x · 答错 y」（11.5sp） |
| 正确率 | 右上角大数（15sp）+ 比例条百分比 | 与答对答错同行的文字（11.5sp） |
| 剩余题数 | 第三格「剩余 n」 | **无此维度**（方案 A 没有） |
| 比例条 | 8dp 绿红分段条 + 注脚 | **无**（方案 A 没有） |
| 卡高 | 约 96dp | 约 77dp（更紧凑，S0 状态整屏不再需要滚动） |
| 视觉重音 | 数字块 + 色条，信息密度高但视觉噪声大 | 环 + 一行文字，重音集中在进度环 |

> 取舍提示：旧实现里的「比例条」与「剩余题数」是上一轮新增、方案 A 中不存在的元素。本轮按“与方案 A 保持一致”的要求移除。若后续仍想保留正确率的分段可视化，可把比例条作为**可选增强**加回（位置建议放在抽屉的本轮小结里，不再占用顶部统计卡）。

## 2. 状态机与状态 → 视觉映射

```
S0 作答中 ──点选项/1-4──▶ 判定 ──┬─▶ S1 判对 ──下一题──▶ S0（或 S3）
                                 └─▶ S2 判错 ──下一题──▶ S0（或 S3）
S3 本轮结束（第 N 题判定后取代 S1/S2 的按钮区）
```

| 状态 | 选项区 | 判定抽屉 | 统计卡 | 题面卡 |
|------|--------|----------|--------|--------|
| **S0 作答中** | 4 项全部可用；悬停淡绿底 `--bg-pale-green`，按下轻微内缩 | 不存在（DOM 无节点） | 显示累计值；进度条停止在当前 | 读音/大意折叠；提示可展开 |
| **S1 判对** | 所选项：绿边 `--green` + 绿底 `--green-pale` + 绿勾；其余项保持中性且锁定；全部转紧凑态 | 绿左条；标题「答对了」+ 勾；正确形态大字 + 读音 + 规则 | 文字行答对 +1、正确率重算；环与进度条不动 | 原位展开读音与大意；提示面板收起 |
| **S2 判错** | 所选项：红边 `--red` + 红底 `--red-pale` + 红叉；**正确答案项：绿虚线边 + 绿勾（揭晓）** | 红左条；标题「正确答案是「X」」+ 叉；正确形态 + 读音 + 规则 + 「已加入错题本」提示 | 文字行答错 +1、正确率重算；环与进度条不动 | 同上 |
| **S3 本轮结束** | 保持最后一题判定态 | 抽屉追加「本轮小结」：答对 / 答错 / 正确率 / 本轮新增错题 + 「再来一轮」+「去错题本」 | 保持最终值 | 同上 |

三重冗余：颜色（绿/红）× 图标（勾/叉）× 边框样式（实线=你选的，虚线=正确答案）。色觉障碍下仍可判读。

## 3. 交互细则

| 交互 | 行为 | 备注 |
|------|------|------|
| 点选项 / 数字键 1–4 | 选择 + 提交一步完成，立即判定 | 判定后选项 `locked`，杜绝连点错判 |
| Enter / 「下一题」 | 抽屉收起 → 选项回 S0 → 题面复位 → 内容滚动回顶部 | 统计卡保持累计值不清零 |
| 规律提示 | 题面卡内原位展开／收起（虚线淡绿面板） | 判定后自动收起，规则改由抽屉承载，不重复占位 |
| 滚动 | 内容区独立滚动；判定后自动滚到抽屉顶部 | 导航栏常驻，不参与滚动 |
| 错题联动 | S2 判定即写入错题本，沿用加权出题（封顶 3）与间隔复习（1/3/7/14/30 天，6 次毕业） | 不弹额外弹窗，只用抽屉内提示条 |
| 本轮小结 | 第 N 题判定后出现；「再来一轮」清零本轮计数、「去错题本」切模块 | 累计统计与错题不清零 |
| 无障碍 | 选项为原生可聚焦控件；Tab 遍历、Enter 激活；判定结果进 liveRegion 播报 | contentDescription 例：「第 2 项，正确」 |

动效令牌：卡片入场 `translateY(6px)→0 / 220ms`；选项着色 130ms；抽屉上滑 220ms；数值与条宽过渡 260–300ms。统一缓动 `cubic-bezier(0.22, 0.61, 0.36, 1)`，**禁弹跳曲线**（P0-3）。

## 6. 验收要点（实现后必须实测）

1. 四态截图（S0/S1/S2/S3）与原型逐项对照一致；
2. **统计卡**：判定后文字行立即更新、环与进度条不动；进入下一题环与进度条前进一格；正确率与抽屉小结数字一致；
3. 选项生成的机械断言：4 项唯一、含正确答案、位置分布近似均匀、误形表每条确实为错误形态；
4. Android 单元测试基线不劣化（当前 22/22）；若新增 quiz 测试则基线上升；
5. 模拟器实测：点选即判、抽屉插入不遮挡选项、自动滚动、小结按钮可用、错题写入正确；
6. 图标接入后实拍三种遮罩下的桌面图标；
7. **跨端一致性**：若同步 Web（待定 Q5），quiz 样例需两端同源比对。

### 实现注意事项（原型阶段已踩到的坑）

| 坑 | 现象 | 规避 |
|----|------|------|
| 滚动容器内子项被压缩 | 判定后抽屉插入使内容变高，带 `overflow: hidden` 的统计卡被压成 2px（CSS 规范：flex 子项非 visible overflow 时 `min-height` 解析为 0） | 原型已用 `.content > * { flex: 0 0 auto }` 固定；Compose 侧对应做法：内容 `Column` 可滚动，子组件用默认 `wrapContentHeight` 且**不要**给统计卡设 `weight()` |
| 平滑滚动干扰截图/自动化 | 判定后自动 `scrollIntoView` 与后续程序化滚动互相覆盖 | 自动化验证时用 `scrollTop = 0` 直赋值并临时关闭 `scroll-behavior` |
